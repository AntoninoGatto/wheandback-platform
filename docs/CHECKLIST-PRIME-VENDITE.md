# Checklist prime vendite vere — Whe&Back®

**Prerequisiti:** step 1–2 (prodotti in shop) + Stripe **test** ok ([`STRIPE-CHECKOUT.md`](./STRIPE-CHECKOUT.md)).  
**Poi:** Stripe live + questa checklist.  
**Bloccati finché non passi qui:** cashback, referral, app.

---

## Prima della vendita live

- [ ] ≥ 10 prodotti published che rispettano le regole qualità
- [ ] Fornitore / partner sa evadere 1 ordine IT
- [ ] Stripe **live** keys solo dopo 1–2 pagamenti test
- [ ] Costi spedizione IT noti (tabella in REGOLE-QUALITA)

---

## Durante / dopo ogni vendita pilota

| Voce | Ok? | Note |
|------|-----|------|
| Pagamento ricevuto (Stripe) | ☐ | |
| Ordine visibile in Admin | ☐ | |
| Vendor / DS notificato | ☐ | |
| Spedizione inviata + tracking | ☐ | |
| Cliente ricevuto | ☐ | |
| Margine reale (prezzo − costo − ship − fee Stripe) | ☐ | |
| Reso / problema? | ☐ | |

---

## Definition of done (step 4)

- [ ] Almeno **3** ordini live completati **oppure** 1 ordine live + 2 test end-to-end documentati  
- [ ] Nessun blocco logistico sconosciuto  
- [ ] Margine accettabile per Antonino  

**Solo allora** aprire [`CASHBACK-DOPO-VENDITE.md`](./CASHBACK-DOPO-VENDITE.md).
